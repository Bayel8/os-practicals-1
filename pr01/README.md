## 4. Создание пользователя и группы

Созданы пользователь `student2` и группа `developers`. Пользователь добавлен в группу.

Команды:

```bash
sudo groupadd developers
sudo adduser student2
sudo usermod -aG developers student2
id student2
getent group developers
```

## 5. Настройка каталога /srv/shared

Каталог принадлежит пользователю `root` и группе `developers`.

Команды:

```bash
sudo mkdir -p /srv/shared
sudo chown root:developers /srv/shared
sudo chmod 775 /srv/shared
ls -ld /srv/shared
stat /srv/shared
```

Фактический результат:

```text
Вставить вывод команд
```

Права `775` означают, что владелец и группа имеют права чтения, записи и выполнения, а остальные пользователи имеют права чтения и выполнения без права записи.

## 6. Проверка создания и удаления файла

Файл `student2.txt` создан от имени пользователя `student2`.

Команды:

```bash
sudo -iu student2
touch /srv/shared/student2.txt
echo "Created by student2" > /srv/shared/student2.txt
cat /srv/shared/student2.txt
exit
rm /srv/shared/student2.txt
```

Фактический результат попытки удаления:

```text
Вставить результат
```

Объяснение:

Для удаления файла необходимы права записи и выполнения на родительский каталог. Если основной пользователь не входит в группу `developers`, он не может удалять записи в каталоге `/srv/shared`, поскольку права для остальных пользователей не включают запись.

## 7. Разница между su и sudo

`su` позволяет переключиться на другого пользователя и открыть его оболочку. `sudo` позволяет выполнить отдельную команду с привилегиями другого пользователя, обычно root, при наличии соответствующих разрешений.

В Ubuntu учётная запись root обычно не имеет установленного пароля для обычного входа. Для административных операций используется `sudo`, что уменьшает риск случайного выполнения опасных команд с максимальными привилегиями.
